# Minimum SDK is 31 (Android 12)

We support Android 12 and newer only. The app takes its whole colour scheme from the wallpaper (dynamic colour, available from API 31), and its core promise is an exact budget alarm whose permission model (`SCHEDULE_EXACT_ALARM`) also starts at API 31. Supporting API 26 would have meant a fallback colour scheme and a second set of alarm and notification code paths; for a free app we chose less code over the extra reach.
